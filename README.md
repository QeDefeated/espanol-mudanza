# Испанский для переезда

Личное веб-приложение для изучения латиноамериканского испанского: карточки с интервальным повторением, топ-1500 слов и темы для переезда, 1000 слов в картинках (иллюстрации Noto Emoji), грамматика, упражнения, диалоги-ситуации с режимом «Я отвечаю», цели и достижения.

Открыть: https://qedefeated.github.io/espanol-mudanza/

## Как устроено

Статический сайт без фреймворков и зависимостей.

- `index.html`, `styles.css` — страница и стили.
- `js/` — модули приложения (обычные скрипты с общим пространством имён `App`):
  `util`, `config`, `state` (прогресс в localStorage), `data` (ленивая загрузка), `audio`, `ai`, `srs` (интервальное повторение), `goals`, `achievements`, `router`, `events`, `main` и экраны в `js/views/`.
- `data/index.json` — стартовый индекс (слова без примеров, названия уроков и сцен, цели). Остальное грузится по требованию и фоном:
  `data/words/<тема>.json`, `data/lessons.json`, `data/dialogs.json`, `verbs.js`, `audio/index.json`.
- `audio/*.json` — записанная нейросетевая озвучка (подгружается при первом прослушивании).
- `sw.js` — Service Worker: офлайн и мгновенные повторные визиты; новая версия применяется по кнопке «Обновить».

Файлы сайта собираются из исходников скриптом сборки (`tools/build.js`), поэтому вручную их здесь не правят.
